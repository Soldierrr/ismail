# Personal Portfolio

This repository contains my personal portfolio website, built from scratch using modern, semantic **HTML** and vanilla **CSS**. 

The goal of this project is to showcase my skills, projects, and experience in a clean, modern, and highly responsive web interface.

## Tech Stack
*   **Structure:** HTML5 (Semantic elements)
*   **Styling:** CSS3 (Custom properties/variables, Flexbox, Grid, Responsive design)

## Directory Structure
*   `index.html` - The main entry point of the portfolio
*   `styles.css` - Custom styling rules and variables
*   `assets/` - Images, icons, and other media files

## Development
To view the site locally, simply open `index.html` in any web browser, or use a local development server like VS Code's Live Server.
