# Prompt for Building the Portfolio Structure

Copy and use the prompt below with an AI assistant to generate the initial, simple structure of your portfolio website:

---

```text
Please build a simple, modern, and highly aesthetic personal portfolio website using a single `index.html` file and a separate `styles.css` file. 

The website should represent a portfolio for a software developer/designer named Ismail.

Please apply the following design and structure requirements:

### 1. HTML Structure (index.html)
- Use semantic HTML5 tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- Header: Navigation bar with links to "About", "Projects", and "Contact", and a text-based logo ("Ismail").
- Hero Section: An eye-catching greeting (e.g., "Hi, I'm Ismail"), a short subtitle about what I do (e.g., "Building clean, modern web experiences"), a call-to-action button ("View My Work"), and a placeholder spot for an illustration or profile image.
- About Section: A short bio text on one side and a grid/list of key technical skills on the other.
- Projects Section: A header and a grid containing 3 project placeholder cards (with project title, brief description, tag list of technologies used, and a "View Project" link).
- Contact Section: A simple, elegant call-to-action inviting collaboration, with email and social media icon links (GitHub, LinkedIn).
- Footer: A simple copyright notice and quick links.

### 2. Styling (styles.css)
- Use a curated, premium color palette. For example, a sleek dark mode theme (rich dark backgrounds, vibrant accent colors like indigo/cyan/purple, and soft border colors).
- Use a modern Google Font (e.g., "Inter" or "Outfit") imported via `@import` instead of standard system fonts.
- Establish clean CSS variables (`--bg-primary`, `--bg-secondary`, `--accent`, `--text-primary`, `--text-secondary`, `--border`) for consistency.
- Implement responsive design using CSS Flexbox and Grid. Ensure it looks beautiful on mobile, tablet, and desktop screens.
- Use modern visual design elements: smooth hover transitions (e.g., scale and color transitions on buttons/cards), subtle gradients, and card borders.
- Keep the design clean, with ample whitespace and clear typography hierarchy.
```
